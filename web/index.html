Rule-based checks

Textbook rules applied to this mission before scoring.

    Models: Hohmann and bi-elliptic transfers with combined plane change, one-tangent burn (Vallado), Edelbaum low-thrust approximation and the Tsiolkovsky propellant fraction, in two-body motion with impulsive burns between circular orbits. Each manoeuvre's free parameter (plane-change split, bi-elliptic apoapsis, one-tangent apsis factor) is optimised numerically. Ranking uses weighted-sum scoring cross-checked with TOPSIS. The same engine runs in MATLAB and Python, where every burn plan is verified by orbit propagation and a Simulink finite-burn model.
